One word for the whole internet. My entry: **feral**.

The internet is not a library, a town square, or a mall. It is a wild animal
that was never house-trained: it hisses, it bites, it steals your food off
the table, and it shows up at 3 a.m. demanding attention. That is the whole
internet, in one word — funny on its own, true of every corner of it, and
not the first word anyone reaches for.

## The entry

`entry.txt` holds the single word `feral` — 5 characters, one word, plain
UTF-8 text. `main.py` is a standard-library-only program that copies it
into the grader's output directory unchanged.

## Running it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The output is byte-identical to `entry.txt` on every run.
